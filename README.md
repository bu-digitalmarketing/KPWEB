# เว็บโปรไฟล์ส่วนตัว — กิตติคม ปล้องนิราศ

เว็บไซต์โปรไฟล์ส่วนตัวแบบหน้าเดียว (HTML + CSS + JavaScript ล้วน ไม่ต้องติดตั้งอะไร)

## วิธีดูเว็บ

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์เล็ก ๆ:

```bash
cd /Users/kittikom/ClaudeCode/KPpersonnalWEB && python3 -m http.server 8080
```

แล้วเปิด http://localhost:8080

## วิธีแก้ข้อมูล

แก้ที่ **`js/data.js` ไฟล์เดียว** — ทุกอย่างบนหน้าเว็บอ่านจากไฟล์นี้
ค่าที่ขึ้นต้นด้วย `TODO:` คือส่วนที่ยังรอข้อมูลจริง

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `name`, `nameEn`, `headline`, `tagline` | ส่วนหัวของเว็บ |
| `avatar` | รูปโปรไฟล์ — วางไฟล์ไว้ที่ `assets/avatar.jpg` |
| `about`, `interests` | ส่วน "เกี่ยวกับฉัน" |
| `stats` | ตัวเลขสรุป 3 ช่อง |
| `experience`, `education` | ไทม์ไลน์ประสบการณ์และการศึกษา |
| `skills` | ทักษะ แบ่งเป็นหมวด |
| `projects` | การ์ดผลงาน |
| `contact`, `socials` | ช่องทางติดต่อ (เว้นว่างไว้ = ไม่แสดง) |

หัวข้อไหนไม่มีข้อมูลเลย เว็บจะซ่อนหัวข้อนั้นให้อัตโนมัติ

## โครงสร้างไฟล์

```
index.html      โครงหน้าเว็บ
css/style.css   ดีไซน์ ธีมสว่าง/มืด และ responsive
js/data.js      ← ข้อมูลส่วนตัว (แก้ที่นี่)
js/main.js      โค้ดแสดงผลและการโต้ตอบ
assets/         รูปภาพ
```

## ฟีเจอร์

- ธีมสว่าง/มืด (จำค่าที่เลือกไว้)
- Responsive ใช้ได้ทั้งมือถือและจอใหญ่
- เมนูเลื่อนตามและไฮไลต์หัวข้อที่กำลังอ่าน
- อนิเมชันตอนเลื่อนหน้า (ปิดอัตโนมัติถ้าผู้ใช้ตั้งค่า reduced motion)
